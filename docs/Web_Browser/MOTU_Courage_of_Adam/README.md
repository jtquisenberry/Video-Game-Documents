## Overview

*He-Man and the Masters of the Universe: The Courage of Adam* is a browser-based game published by Cartoon Network UK on **October 2, 2003**, to coincide with the 2002–2004 animated series reboot of *He-Man and the Masters of the Universe*. The game was hosted on the UK Cartoon Network website and built using **Macromedia Director** (later Adobe Director), delivered as a `.dcr` (Director Compressed Runtime) Shockwave file — the standard format for interactive web content of that era.

The original hosting environment is no longer active. The Cartoon Network UK website no longer serves this content, and Shockwave/Director plugin support has been dropped by all major browsers. The game survives through captures in the **Wayback Machine** (Internet Archive) and partial references on third-party game aggregator sites.

## Technical Context

### Macromedia Director / Shockwave

Macromedia Director was the dominant platform for interactive multimedia and browser games throughout the late 1990s and early 2000s. Director-authored content was distributed as `.dcr` (Director Compressed Runtime) or `.dir` (uncompressed) files and delivered to browsers via the **Macromedia Shockwave Player** plugin.

Adobe acquired Macromedia in 2005 and continued publishing Director until version 12 (2014). Adobe formally discontinued the Shockwave Player in **April 2019**, after which all major browsers removed plugin support. This renders the original game file inaccessible without specialized emulation.

| Technology | Detail |
|---|---|
| **Runtime** | Macromedia Shockwave Player |
| **File format** | `.dcr` (Director Compressed Runtime) |
| **Language** | Lingo (Director's scripting language) |
| **Browser plugin status** | Discontinued April 2019 (Adobe) |

## Preservation Notes

This record documents the existence and original publication context of *The Courage of Adam* for research and archival purposes. The `.dcr` binary captured by the Internet Archive on October 2, 2003 represents the most complete preservation of this game currently known.

Researchers interested in recovering and playing this game should:

1. Download the `.dcr` from the Wayback Machine capture linked above.
2. Investigate current Director/Shockwave emulation projects, particularly [Dirplayer](https://github.com/igorlira/dirplayer-rs).
3. Consult the [Internet Archive's Software Library](https://archive.org/details/softwarelibrary) for any uploaded playable version.

The series ran from 2002 to 2004 and introduced a modernized visual style that influenced associated merchandise and digital content of the period, including this browser game.

## Overview

*He-Man and the Masters of the Universe: Lair of the Slime Mutant* (also known as *He-Man Slime Pit*) is a browser-based game published by **Toonami UK** on the Cartoon Network UK website, released on **April 7, 2004**. Like *The Courage of Adam* (2003), it was built using **Macromedia Director** and distributed as a `.dcr` Shockwave file.

The game's title references the **Slime Pit**, an iconic Masters of the Universe playset from the original 1980s toy line — a pit of monster-controlled slime used to enslave heroic warriors. The game was part of Toonami UK's interactive content hub, which hosted Flash and Shockwave games to accompany animated series broadcasts.

## Thematic Context: The Slime Pit

The **Slime Pit** is one of the most recognizable playsets in the original Masters of the Universe toy line (Mattel, 1985). The playset featured a monster-headed throne from which green slime could be poured over heroic figures, "enslaving" them to Skeletor. The playset was memorably depicted in the original 1980s animated series and in comic media. Its use as a game title in 2004 connects to the 2002–2004 animated series reboot, which revived these classic elements for a new generation.

# Dragon Edge Pinball – Mobile Bonus Indicator Field Notes

These notes preserve an unresolved gameplay question about the mobile/cell-phone version of *Dragon Edge Pinball*. The source does not identify a handset, operating system, developer, or release date.

## CLR Subscreen

Pressing **CLR** pauses the game and opens a subscreen with a grid of dots indicating which bonuses have been found. The source illustrates the two target indicators in the second column:

```text
O x O O
O x O O
```

The author occasionally activated the upper and lower target indicators while scoring millions of points and defeating the dragon. The upper target was observed to award 100,000 points. The source did not determine what actions trigger either target; it describes their activation as appearing random.

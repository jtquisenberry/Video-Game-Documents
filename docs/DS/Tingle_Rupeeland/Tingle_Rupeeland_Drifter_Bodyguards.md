# Freshly-Picked Tingle's Rosy Rupeeland - Drifter Bodyguard Field Note

## Yamori and Ronny

The source note identifies screenshots for the hiring locations of Yamori and Ronny. It does not include local image files; the original GameFAQs image references are retained here:

- [Yamori hiring-location image (GameFAQs image 26)](https://gamefaqs.gamespot.com/ds/930503-freshly-picked-tingles-rosy-rupeeland/images/26)
- [Ronny hiring-location image (GameFAQs image 27)](https://gamefaqs.gamespot.com/ds/930503-freshly-picked-tingles-rosy-rupeeland/images/27)

The reported search procedure is:

1. Save the game.
2. Travel to the location shown in the screenshot.
3. If the bodyguard is present, hire him. If not, power off the DS, restart it, and reload the saved game.
4. Repeat the search.

The author reports finding Yamori after four tries, while noting that some players took more than 20 attempts. Before Yamori can be hired, the source says he must first be found in four of five static locations: Sunshine Seashore, Cape Treasure, Lon Lon Meadow, Deku Forest, and Steamy Marsh. A third GameFAQs image reference shows the Steamy Marsh location:

- [Yamori at Steamy Marsh (GameFAQs image 28)](https://gamefaqs.gamespot.com/ds/930503-freshly-picked-tingles-rosy-rupeeland/images/28)

## Teddy Todo

The source reports finding Teddy Todo six times in different places. Unlike the other bodyguards described, he speaks when Tingle enters a screen containing him; the player then has about 30 seconds to locate him on that screen. No locations or image references for those six encounters were included.

## Overview

*Masters of the Universe VR* (Android) / *View-Master Masters of the Universe VR* (iOS) is a **virtual reality experience** developed and published by **Mattel**, released in October–November 2016. The experience is designed for use with **Mattel's View-Master VR** headset — a Google Cardboard–compatible plastic viewer shaped like the classic View-Master toy — transforming a smartphone into a VR display.

The iOS version launched one day before the Android version: **October 31, 2016** (iOS) and **November 1, 2016** (Android). Both versions share the same underlying VR content, with platform-specific naming reflecting Mattel's branding choices.

## Hardware Context: View-Master VR

The **Mattel View-Master VR** is a smartphone-based virtual reality headset styled after the iconic View-Master slide viewer toy (originally introduced in 1939). The VR version holds a smartphone in front of two lenses, using Google's **Cardboard SDK** to render stereoscopic 3D content.

| Feature | Detail |
|---|---|
| **Form Factor** | Plastic headset holding smartphone |
| **Standard** | Google Cardboard compatible |
| **Lens Type** | Stereoscopic dual lenses |
| **Input** | Smartphone touchscreen / Cardboard button |
| **Content Delivery** | App-based VR experiences (this app is one) |
| **Target Audience** | Family / Children |

The View-Master VR was marketed alongside licensed experience packs (physical reel cards) and companion apps like this one. Each companion app provided a branded VR environment tied to a franchise — in this case, Masters of the Universe.

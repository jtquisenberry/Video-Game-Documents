## Overview

*Masters of the Universe – He-Man: Power of Grayskull* is an isometric action-adventure game released in 2002 for the Game Boy Advance by TDK Mediactive. Players guide He-Man across Eternia using isometric navigation, sword combat, running maneuvers, and parries.

This reference lists the foundational controls and movement mechanics for the game.

---

## Controls Reference

| Button / Input | Action | Function / Description |
| :--- | :--- | :--- |
| **Up** | Walk Up | Moves He-Man upward across the screen. |
| **Down** | Walk Down | Moves He-Man downward across the screen. |
| **Left** | Walk Left | Moves He-Man to the left. |
| **Right** | Walk Right | Moves He-Man to the right. |
| **Two Directions (Simultaneous)** | Walk Diagonally | Press two adjacent directional buttons simultaneously to walk diagonally through isometric environments. |
| **B Button** | Attack | Swings the Power Sword to strike enemies and clear destructible hazards. |
| **A Button** | Jump | Jumps vertically to cross gaps or evade low ground attacks. |
| **Left Shoulder (L)** | Run | Hold the **L** shoulder button while pressing a direction on the D-Pad to run/sprint. |
| **Right Shoulder (R)** | Parry | Defend/parry with the Power Sword to block or deflect enemy strikes. |
| **Start** | Pause | Pauses gameplay and opens the in-game menu. |

---

## Navigation & Combat Notes

* **Isometric Movement:** Because the game renders terrain from an isometric perspective, navigating tight corridors or bridges often requires combining two directional inputs (e.g., Up + Right) for clean diagonal movement.
* **Running Velocity:** Holding the **Left Shoulder (L)** button while moving accelerates He-Man into a sprint, which is essential for evading missile projectiles and jumping wider gaps.
* **Defensive Parrying:** The **Right Shoulder (R)** button parry must be timed against enemy attack frames to mitigate incoming damage effectively.

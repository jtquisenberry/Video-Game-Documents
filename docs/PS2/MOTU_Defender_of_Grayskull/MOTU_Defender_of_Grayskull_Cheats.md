## Overview

*Masters of the Universe: He-Man: Defender of Grayskull* is a 3D action game released on PlayStation 2 in 2005. Players control He-Man across a series of missions set on Eternia, defending Castle Grayskull against Skeletor's forces. The game was originally planned for Nintendo GameCube and Xbox as well, but those versions were never released.

The cheat codes below are entered through the **Options Menu**, which features a dedicated cheat-code entry section accessible from the main menu.

---

## How to Enter Codes

1. From the **Main Menu**, select **Options**.
2. Navigate to the **Cheat Code** entry section.
3. Enter the button sequence using the PlayStation 2 controller's directional pad and face buttons.
4. A confirmation sound or message will indicate successful entry.

## Cheat Codes (PlayStation 2)

All codes use the PlayStation 2 controller. Directional inputs refer to the D-Pad. Face buttons use standard PS2 notation: **X** (Cross), **O** (Circle), **△** (Triangle), **□** (Square).

| Effect | Button Sequence |
|---|---|
| **Invulnerability** | RIGHT, O, UP, LEFT, X |
| **Unlock All Levels** | X, LEFT, UP, O, DOWN |
| **Unlimited Grayskull Power** | DOWN, RIGHT, X, O, DOWN |
| **Double Damage** | O, RIGHT, X, UP, X |

## Code Details

### Invulnerability
```
RIGHT, O, UP, LEFT, X
```
He-Man becomes immune to all damage. Useful for exploring areas, completing missions without health management, or simply experiencing the story.

### Unlock All Levels
```
X, LEFT, UP, O, DOWN
```
Unlocks all mission stages immediately, allowing the player to begin any level without completing prior stages. Useful for direct access to later content or replaying specific missions.

### Unlimited Grayskull Power
```
DOWN, RIGHT, X, O, DOWN
```
Grants infinite Grayskull power, the resource used for special attacks and abilities. With this code active, He-Man can use his most powerful moves without restriction.

### Double Damage
```
O, RIGHT, X, UP, X
```
Doubles all damage He-Man deals to enemies. Stacks with other gameplay mechanics to dramatically reduce enemy health pools, enabling rapid completion of combat encounters.

## Notes on Unreleased Versions

The original development plan included releases for **Nintendo GameCube** and **Xbox** alongside the PlayStation 2 version. Neither platform version was commercially released. The PlayStation 2 edition is therefore the only retail version of this title. All codes listed above are specific to the PS2 version.
